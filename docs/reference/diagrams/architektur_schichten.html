Warum zwei Pfade?

Nur analyse.py (Submit-Formular) stößt die LLM-Pipeline an. Die restlichen fünf Router liefern bereits gespeicherte Analysen aus — dafür braucht es kein erneutes Scraping oder LLM-Calls, nur einen ChromaDB-Read.

Querschnitt statt eigener Schicht

__init__.py, config.py, logging_config.py und agents/errors.py werden von Modulen in mehreren Schichten gleichzeitig importiert (CLI, Feed, Analyzer) — sie gehören keiner Schicht exklusiv an.

Adapter als Fassade

Die Analyse-Pipeline kennt nur llm_adapter.get_instance(provider) — welcher Provider (CLI, Copilot, Gemini, Mistral, …) dahintersteckt, entscheidet allein die Registrierung in __init__.py.
